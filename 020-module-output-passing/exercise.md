# Module Output Passing Exercise

**Exam Question:** Your root module calls a database module that outputs the connection string. It then calls a webapp module that needs this connection string. How do you correctly pass the database connection string from the database module to the webapp module?

## Steps

### Part 1 — Inspect the module structure

1. **Examine the database module outputs:**

   ```bash
   cat modules/database/outputs.tf
   ```

   The database module declares three outputs: `connection_string`, `db_host`, and `db_port`. These outputs are available to the root module via `module.database.<output_name>`.

2. **Examine the webapp module's input:**

   ```bash
   cat modules/webapp/main.tf
   ```

   The webapp module expects a `db_connection_str` input variable of type `string`.

3. **Examine how the root module connects them:**

   ```bash
   cat main.tf
   ```

   The root module passes the database output directly:

   ```hcl
   module "webapp" {
     db_connection_str = module.database.connection_string
   }
   ```

### Part 2 — See it working

4. **Initialize and apply:**

   ```bash
   terraform init
   terraform apply -auto-approve
   ```

5. **Verify the connection string flowed through:**

   ```bash
   terraform output db_connection
   ```

   This shows the connection string generated by the database module.

   ```bash
   cat modules/webapp/app-config.txt
   ```

   The webapp module received the value and wrote it to its config file — proving the output was successfully passed.

### Part 3 — Experiment with incorrect syntax

6. **Try the incorrect syntaxes from the exam:**

   Edit `main.tf` temporarily (then revert) to see the error:

   ```hcl
   # WRONG: using output. prefix
   db_connection_str = output.database.connection_string
   ```

   Error: `Reference to unknown resource: "output"`

   ```hcl
   # WRONG: using var. prefix
   db_connection_str = var.database.connection_string
   ```

   Error: `Reference to unknown variable: "var.database"`

   The only valid syntax to reference a module output is:

   ```hcl
   db_connection_str = module.database.connection_string
   ```

### Put It Together

```hcl
module "database" {
  source = "./modules/database"
  name   = "prod-db"
}

module "webapp" {
  source            = "./modules/webapp"
  db_connection_str = ???
}
```

Which syntax correctly passes the database connection string from the database module to the webapp module?

- A. `db_connection_str = output.database.connection_string`
- B. `db_connection_str = module.database.connection_string`
- C. `db_connection_str = var.database.connection_string`
- D. Define the output inside the database module pointing to webapp
